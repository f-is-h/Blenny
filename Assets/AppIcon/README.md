# Application icon source

`BlennyAppIcon.png` is the production 1024-by-1024 raster source. Version 0.13.0
uses the owner-approved `11-balanced-rock-water-window.png` from the
v13 design exploration, resized from 1254 by 1254 without cropping or changing
the artwork.
The build derives the multi-resolution `BlennyAppIcon.icns` from this PNG.
An SVG master is not required.

This replaces the previous `09-natural-cirri-connection.png` trial; the menu bar
template remains the selected face-silhouette A design.

`BlennyAppIconMaster.svg` preserves the historical v12 artwork; it is not the
source of the current PNG and is not packaged.
